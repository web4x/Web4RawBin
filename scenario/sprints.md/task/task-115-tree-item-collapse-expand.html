Task Description

Two distinct interactions on the tree-item: - **Tap the icon** (R16.7): first tap **collapses** the item to just the quadratic icon (T113); tap again **expands** to show name + description (T112). - **">" children expander** (R16.8): on the **right side**, show a ">"-like icon when the item has children; clicking it **expands the subtree** in the tree. These are separate from OS drag (T114) — distinguish tap vs drag.
