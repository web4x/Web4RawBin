Task Description

Two integrations that complete the nav loop on `/trace` + `/md/`: **T127.1 — cross-nav between browsers:** - Every node in `/trace` (rb-trace-tree + DetailViews) exposes a "Open file" link → navigates to the file's `/md/` view. - Every file in `/md/` whose unit lives in the scenario index exposes an "Open in trace" link → navigates to `/trace#<class>.show?ior=<...>`. **T127.2 — IOR universal-reference handler:** - Any file in the repo (md, ts, puml, json) is a unit, identified by an IOR. - IOR resolves to: (a) the file path, (b) the unit's class (when in `scenario/index/`), (c) the rendered view. - A "Resolve IOR" endpoint (or client-side resolver) takes an IOR and returns `{ filePath, class, htmlView, mdView }`.
