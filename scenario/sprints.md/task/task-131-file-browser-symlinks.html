Task Description

**Problem (architect-diagnosed in the impl commit):** `FileApi.readDir()` did not follow symbolic links — the `scenarios/sprints.json/sprint-1/...` symlink tree generated by T125.3 + T128.1 was invisible / untraversable in the file-browser served at `/md/`. **Design (architect, per the impl commit):** - `FileApi.readDir()`: detect symlinks via `isSymbolicLink()`, resolve type via `statSync(target)` (dir or file). Add `symlink: true` to `DirEntry`. Broken symlinks silently skipped (no entry emitted). - `rb-file-tree`: render a `🔗` marker after the name for any entry whose `symlink === true` (visual cue that it's a link target). - `/md/` handler was already symlink-correct from 60d6e36 (no change needed there). **Impl (expert, aad0816 v0.5.30):** - `src/ts/server/FileApi.ts` readDir() — symlink detection + target-stat type resolution - `src/public/ts/trace/rb-file-tree.ts` — 🔗 marker on symlinked entries - 818/818 pass
