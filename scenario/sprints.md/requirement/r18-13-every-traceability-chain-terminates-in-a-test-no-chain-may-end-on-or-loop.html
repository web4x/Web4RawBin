This is either: (a) a LOGIC bug — the chain walker follows a wrong forward-link type (e.g. Implementation has a `tasks[]` field that it shouldn't follow), or (b) a DATA QUALITY bug — Implementation units have incorrect forward references pointing to Task IORs instead of Test IORs.
