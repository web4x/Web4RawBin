# R30.6.8 — Re-architect the diff/merge editor onto CodeMirror 5 MergeView (retire in-house LCS)

**Author:** robbin-architect 2026-07-13 (DESIGN-ONLY; req = sole minter, S30 backlog, TRON-authorized). Goal: a real 3-pane merge view — **left | CENTER-merged-editable | right**, sync-scroll, copy-across — resolving the OOSH version issue.

## Decision trail (converged)
- ✗ **Monaco `createDiffEditor`** — 2-FILE ONLY (original vs modified); composing 2 is NOT a true 3-way merge (Tron). Monaco stays the main *code* editor (rb-code-editor), not the merge view.
- ✗ **CM6 `@codemirror/merge`** — mainly 2-way; no first-class 3-pane merge.
- ✗ **@codingame/monaco-vscode-api** — true parity but heavy re-platform of our plain-AMD Monaco.
- ✅ **CodeMirror 5 `MergeView` (3-pane)** — purpose-built for EXACTLY this (Tron research-confirmed, codemirror.net/5/demo/merge.html): `value`=center (merged, editable), `origLeft`=left, `orig`=right, `connect:'align'` (sync-scroll + row alignment), copy-across arrows (`revertButtons`), `highlightDifferences`. **This is the pick.**

## Spike verification — CM5 MergeView fit
- **3-pane merge:** `CodeMirror.MergeView(el, { value: center, origLeft: leftText, orig: rightText, connect: 'align', collapseIdentical: true, highlightDifferences: true, revertButtons: true })` → left + right read-only reference panes flanking an **editable center** (the merged result); per-chunk **copy-across arrows** merge a side's chunk into center; `connect:'align'` gives sync-scroll + aligned rows. This IS Tron's spec, out of the box.
- **Diff engine:** CM5's `addon/merge/merge.js` needs a global `diff_match_patch` (google-diff-match-patch) — load it alongside.
- **Bundle / load:** CM5 core (~150kB) + `addon/merge/merge.js` + `diff_match_patch` (~50kB) + `merge.css` + `codemirror.css`. **Lazy-load via CDN** (cdnjs) only when the diff view opens — same pattern as Monaco's lazy CDN load; not currently installed (new).
- **Coexist with Monaco:** ✅ clean — Monaco (`monaco.*`) remains the main code editor; CM5 (`CodeMirror.*`) is scoped to rb-diff-editor only. Different globals, different DOM, no conflict. Trade-off = two editor engines in the (lazy) bundle — accepted because Monaco cannot do a 3-pane merge and CM5 MergeView is the purpose-built tool.

## Re-architecture (REPLACE in-house LCS; Class RbDiffEditor 18165081 REUSE)
rb-diff-editor.ts (268 LOC of 3-textarea + LCS + manual gutter) → a thin CM5 MergeView host:
- **`connectedCallback`** RE-SCOPE — lazy-load CM5 (+merge+diff_match_patch) via a shared `cmMergeLoader`, then mount the MergeView shell.
- **`loadSide`** RE-SCOPE — set the MergeView panes: `left`→`origLeft`, `right`→`orig`, initial `center`→`value` (default center = left or empty). Content still comes from GitApi/RepoRegistry (file@ref / working file).
- **`save`** KEEP — write the center (`mergeView.editor().getValue()`) via `/api/files` (mtime-guard).
- **`pickRef` / `pickFile` / `swapSides`** KEEP — swapSides swaps `origLeft`↔`orig` (re-scope to reconfigure MergeView).
- **`computeDiff` (Impl 15843ac9, LCS)** RETIRE — CM5 + diff_match_patch does the diffing.
- **`renderHunks` (Impl 37636aaa, manual gutter/scroll)** RETIRE — CM5 renders the gutter, highlights, and sync-scroll.
- **`takeHunk` (Impl 6ebfac12, manual take-over)** RETIRE — CM5's copy-across arrows (`revertButtons`) ARE the take-over, for free.
- **NEW `RbDiffEditor.mountMergeView`** — construct the `CodeMirror.MergeView` with the 3-pane config above.
- **NEW `cmMergeLoader`** (shared util) — memoized promise that lazy-loads CM5 core + merge addon + diff_match_patch + CSS from CDN.
- **KEEP orthogonal:** `GitApi` (branches/commits/fileAtRef — feed left/right content), `RepoRegistry` (repo targeting, R30.6.7).

## Open decision for PO/Tron
**CM5 (two-engine: Monaco code editor + CM5 merge view) vs. eventually unifying on one engine.** Recommend **CM5 MergeView now** (it's the right tool, lazy-loaded, isolated to the diff view) — unifying editors is a separate, larger effort not worth blocking the merge feature.

## AC sketch
- Open diff → CM5 MergeView: left + right reference panes + editable center, sync-scrolled + row-aligned (`connect:'align'`), differences highlighted.
- Copy-across arrow on a chunk merges that side into center; center is editable; save writes center to `/api/files`.
- CM5 lazy-loads only when the diff view opens; coexists with Monaco (main editor) with no global/DOM conflict.
- GitApi/RepoRegistry still feed left+right content (incl file@ref, OOSH repo via key-allowlist).
