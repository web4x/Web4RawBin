# R30.10 — Right-side default = the file's git history

**Author:** robbin-architect 2026-07-13 (DESIGN-ONLY; req = sole minter, S30). R30.9 accepted "amazing" → next. On opening the diff/merge for a **git-tracked** file, the RIGHT-side selector **defaults to all versions of THAT file** in the selected repo's history (LEFT=current working file, RIGHT=browse-its-history, default = most-recent committed version). crossRef **R30.9** (rb-diff-editor) + **R30.6.7** (RepoRegistry).

## Measured baseline
- **GitApi 795e328d = 5m** (branches/commits/fileAtRef/guardRef/mergeBase) → **6m** with fileHistory.
- **RbDiffEditor 18165081 = 16m**; right side (`this.right` = REMOTE) already has a repo `<select>` + `📁 pickFile` + `⎇ pickRef`; `loadSide('right',{path,ref,content})` loads working file (`/api/files`) or file@ref (`/api/git/file` = fileAtRef).
- No existing fileHistory/rightHistory — fresh.

## Design
### (1) NEW `GitApi.fileHistory(root, path)` (GitApi 5→6m)
`execFile('git', ['log','--follow','--pretty=format:%H%x00%aI%x00%an%x00%s','--', path], {cwd: root, timeout, maxBuffer})` → parse NUL-delimited → `[{sha,date,author,subject}]` (newest-first; `--follow` tracks renames). **Read-only, execFile array-args (no shell).**
**Guarding (precise):** input is a **PATH** not a ref → guard via **RepoRegistry.resolve(repo)** (root from allowlist key) + existing **safeRelPath** (no `..`, within-root). `guardRef` is for the *ref* on the subsequent `git show` (step 2), NOT fileHistory's path. Endpoint `GET /api/git/file-history?repo=<key>&path=<relPath>` → JSON list.

### (2) NEW `RbDiffEditor.populateRightHistory(path)` (RbDiffEditor 16→17m)
On diff open for a git file: `GitApi.fileHistory(repo, path)` → populate a right-side **history `<select>`** (new `.de-history`, distinct from the repo select) with the commit list → **DEFAULT-select newest** and `loadSide('right', {ref: sha, path})` (existing loadSide → fileAtRef → `git show <sha>:<path>`). Older pick → same loadSide with that sha. LEFT stays the current working file (R30.6.6 `showDiff(currentFilePath)`) → default view = "working vs last commit," history a dropdown away.

### No-history / non-git fallback
- `fileHistory` empty (untracked/new file, path not in history, non-git working file) → history select shows **"no history"**, **no default**; RIGHT stays on manual `pickFile`/`pickRef` — graceful, unchanged.
- History-default engages ONLY when the file HAS git history; `pickRef`/`pickFile` remain manual overrides.

## AC sketch
- Open diff on git-tracked file → RIGHT history select populated (newest-first, `--follow`), defaults to most-recent committed version; LEFT = current working file.
- Pick older commit → RIGHT reloads that version (`git show <sha>:<path>`); base-aware merge (R30.9) recomputes.
- Untracked/non-git → "no history", RIGHT manual fallback (no default).
- Security: path via RepoRegistry.resolve + safeRelPath (no `..`/abs); execFile array-args; read-only; unknown repo key → 400.
- `GitApi.fileHistory` returns correct newest-first list for a known path (parse test).
