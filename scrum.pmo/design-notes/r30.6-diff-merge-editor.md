# R30.6 — 3-pane diff/merge editor (`rb-diff-editor`)

**Author:** robbin-architect 2026-07-13 (DESIGN-ONLY; req is single minter). A new editor component to compare two sources (working file or file@git-ref) side-by-side and merge selected hunks into an editable center result.

**DECISIONS RATIFIED (PO/Tron 2026-07-13):** (1) **in-house LCS line-diff** — no new dependency, `computeDiff` = pure DOM-free unit-testable fn. (2) **`GitApi` as its own Class** — isolated git ops + ref-allowlist security in one place (satisfies R27.5 one-class-per-file, testable). Both dep-gates cleared → the FULL chain (incl `computeDiff` + `GitApi`) is mintable.

## Measured stack constraints (design is grounded in these)
- **No diff/editor lib installed** (no CodeMirror/monaco/jsdiff in package.json). → panes are **textareas**, diff is an **in-house line-diff** (no new dependency unless req/PO decide to add one).
- **No git endpoints** exist yet — but the server already imports `execFile`/`execFileAsync` (server.ts:19/492) and runs `execFileSync('plantuml', …, {timeout})` (1263). → add read-only git endpoints the same way (array args = no shell injection).
- **Editor is component-based** (`edit.ts` hosts `rb-editor-layout`/`rb-file-tree`/`rb-code-editor`/`rb-preview`/`rb-editor-toolbar`). Convention: `class RbX extends HTMLElement { connectedCallback() }` + `customElements.define('rb-x', RbX)`. Files via `GET/POST /api/files/<path>`; `rb-file-tree` emits `file-select {path}`.
- **Reuse:** `RbFileTree` (R30.5) as the file-chooser; `GET /api/files/` for working content; the `PROJECT_ROOT`/`safePath` guard for all path access.

## Semantics
Left + Right are two **sources** (each chosen via file-chooser + optional git-ref picker); **Center** is the **editable merged result**. Per-hunk take-over buttons push a hunk's Left or Right text into Center. `swap` exchanges Left↔Right. (A true 3-way with a common merge-base is a future extension; the core is Left/Right compare → merge-into-Center, which needs no base.)

## Component — `RbDiffEditor extends HTMLElement` (new, `src/public/ts/components/rb-diff-editor.ts`)
Methods (name-matching — each is the exact decl the expert writes so its `[impl:uuid]` marker AST-attaches):

| Method | Responsibility |
|---|---|
| `connectedCallback` | Build the 3-pane shell + per-side toolbar (file-chooser btn, ref-picker btn, swap, save). |
| `loadSide` | `loadSide(side:'left'|'right', src)` — fetch content from a working file (`/api/files`) or a file@ref (`/api/git/file`), set the pane, trigger recompute. |
| `computeDiff` | Pure **in-house LCS line-diff** of Left vs Right → `hunks[] {type:'add'|'del'|'change', leftRange, rightRange, lines}`. DOM-free → unit-testable in isolation. |
| `renderHunks` | Paint hunk highlights in Left/Right; insert per-hunk take-over buttons (◄ take-left / take-right ►) in the Center gutter. |
| `takeHunk` | `takeHunk(hunkId, side)` — apply that side's hunk text into the Center merged buffer at the aligned range; re-render + mark dirty. |
| `swapSides` | Exchange Left↔Right content + refs, recompute. |
| `pickRef` | `pickRef(side)` — open the git-ref picker (branch+commit list from GitApi), set the side's ref, `loadSide`. |
| `pickFile` | `pickFile(side)` — open an `rb-file-tree` chooser (REUSE R30.5), on `file-select` set the side's path, `loadSide`. |
| `save` | POST the Center merged content via `/api/files` (mtime-guarded like `edit.ts saveFile`). |

**Diff algorithm:** classic LCS over lines (DP table → backtrack to keep/add/del → coalesce adjacent into hunks). Sufficient for typical file sizes; Myers is a drop-in optimization later. Keep `computeDiff(leftLines, rightLines) → hunks` a pure function for testability.

## Server — `GitApi` (new logical class, 3 read-only endpoints in server.ts; monolith allowlisted per R27.5 axis-3)
| Method | Endpoint | Impl |
|---|---|---|
| `GitApi.branches` | `GET /api/git/branches` | `execFile('git',['branch','--format=%(refname:short)'],{cwd:PROJECT_ROOT,timeout})` → JSON list. |
| `GitApi.commits` | `GET /api/git/commits?path=&limit=` | `execFile('git',['log','--format=%H%x00%s%x00%an%x00%aI','-n',limit, '--', path?])` → `[{hash,subject,author,date}]`. |
| `GitApi.fileAtRef` | `GET /api/git/file?ref=&path=` | `execFile('git',['show',`${ref}:${path}`],{cwd:PROJECT_ROOT,timeout})` → content. |

**Security (mandatory):** `execFile` with **array args** (never `exec`/shell). Validate `ref` against `^[\w./-]+$` and reject otherwise; resolve `path` through the existing `PROJECT_ROOT`/`safePath` guard (no `..`, within project). Read-only git verbs only (`branch`/`log`/`show`) — never `checkout`/`write`. Apply a timeout + `maxBuffer` like the plantuml call.

## AC sketch (for req)
- Choose a working file on Left + a file@branch on Right → both panes populate; diff hunks highlight.
- Take-over a Left hunk and a Right hunk → Center reflects both; save writes Center to `/api/files` (mtime-guarded).
- Git-ref picker lists branches + recent commits; selecting one loads that file@ref via `git show`.
- `swap` exchanges sides + recomputes. Invalid/oversized ref → 400, no shell execution (execFile array args).
- `computeDiff` unit test: given two line arrays, returns correct add/del/change hunks (pure, DOM-free).
