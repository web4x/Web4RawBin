# R30.5 — Editor file-pane empty: root dir must send EMPTY relPath, not '/'

**Author:** robbin-architect 2026-07-13 (DESIGN-ONLY; req is single minter per the R29.9 dispatch-side rule). Symptom: the editor's file tree pane renders empty — no files at all.

## Root cause (MEASURED, confirms the relayed diagnosis)
`rb-file-tree.ts` loads the root with `this.loadDir('')` (line 19). Inside `loadDir` (line 29), the fetch is:
`fetch(`/api/files/${encodeURIComponent(dirPath || '/')}`)` (line 31).
For the ROOT call `dirPath=''`, the expression `'' || '/'` evaluates to `'/'` → `encodeURIComponent('/')='%2F'` → request `GET /api/files/%2F`.
Server (`server.ts`): line 1283 `relPath = decodeURIComponent(...)` → `relPath='/'`; `safePath('/')` resolves to the FILESYSTEM root, which fails the `PROJECT_ROOT` guard → **Forbidden** → the tree renders empty.
The correct root request is `GET /api/files/` (empty) → server line 1301 treats `relPath===''` as a dir → `readDir('')` = project root → full tree (PO verified live: `/api/files/` works, `/api/files/%2F` forbidden).

## Fix (minimal, one line)
`rb-file-tree.ts:31` — drop the `|| '/'` fallback: `fetch(`/api/files/${encodeURIComponent(dirPath)}`)`.
- root `dirPath=''` → `/api/files/` → `readDir('')` → project root ✓
- subdir `dirPath='sub/'` → `/api/files/sub%2F` → `readDir('sub/')` ✓ (unaffected)

The `|| '/'` only ever changed the empty-root case, and it is exactly what broke it. Lines 34 (`container = dirPath ? … : this`) and 36 (`if (!dirPath) container.innerHTML=''`) already treat `''` as root correctly, so no other change is needed.
