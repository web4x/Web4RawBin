## The invariant
A new Sprint unit is a governance act, not an agent convenience. From **Sprint ≥ 30**, a Sprint unit must carry a **Tron-authorization record**; an agent-minted sprint without it is a violation.

## Authorization record shape (on the Sprint unit)
```
ior:class:Sprint
model: {
  ..., 
  tronAuthorization: {
    authorizedBy: 'Tron',
    ref:  string,        // the Tron directive/message ref that authorized it (evidence, like an AC's evidence-prose)
    at:   string,        // ISO timestamp of the authorization (stamped, not agent-generated)
  }
}
```
The record is EVIDENCE (a pointer to Tron's directive), the same shape as AC evidence-prose — auditable, not forgeable-by-convention.
