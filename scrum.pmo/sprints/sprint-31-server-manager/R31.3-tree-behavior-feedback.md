## ⚠ Two tree behavior/structure bugs (Tron)
1. **Window node "0: bash" is a placebo → should be "window 0" WITH expand/collapse children.** The middle (window) level is labeled by window-index + active command ("0: bash") and has **NO expand/collapse chevron** (session nodes DO have chevrons; the window node doesn't). Tron: *"the bash 0 is somehow a placebo. it should be window 0 and also have expand/collapse children."* FIX: window nodes get (a) a clear WINDOW label (window index/name, e.g. "window 0" — not the placebo active-command), (b) their OWN expand/collapse chevron toggling their pane children.
2. **Expansion is not layer-by-layer.** Tron: *"initially its closed state, yet open and once closed opens the tree and not layer per layer. once i manually opened and closed each session the tree expansion starts to behave naturally."* Expanding a node currently explodes the whole subtree (windows AND panes at once); it only settles after manually toggling each session. FIX: progressive/lazy expand — a node reveals ONLY its direct children (collapsed), one layer at a time (session → windows → panes); correct initial collapsed state; each node toggles independently.
