### BUG-1 — endless zoom-out capped: ROOT = MIN=0.25 hard floor (+ grow-mode dead tx/ty path)
zoomAbout (pan-zoom.ts:132): ns=max(MIN,min(MAX,scale*factor)) with MIN=0.25 (:18) → zoom-out CANNOT go below 0.25 = HARD FLOOR (not endless). COMPOUNDING (why v0.8.31 feels worse): in grow mode at scale<1, apply() uses IDENTITY transform + native scroll, so clamp()'s tx/ty-centering + zoomAbout's about-point math (tx'=px−f·(px−tx)) are DEAD → zoom-out below 1 no longer zooms about the cursor + slams the 0.25 wall.
FIX DIR (endless + canvas-grow together): (1) drop/greatly-lower MIN for grow mode (e.g. 0.05 or no floor) so canvas keeps growing (base/scale) + a MAX-CANVAS-PX safety (~16000px, avoid browser limits) = endless-in-practice; (2) grow-mode zoom-about via NATIVE SCROLL (after onCanvasGrow set surface.scrollLeft/Top to keep the cursor-point stationary; clamp() no-op in grow mode). Preserve v0.8.31 canvas-grow. req AC: "zoom-out ALWAYS possible (repeated, no blocking floor) AND canvas grows each step."
