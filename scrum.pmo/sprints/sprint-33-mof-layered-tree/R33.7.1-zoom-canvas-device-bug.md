## THE BUG (device-QA catch on R33.7.1)

Tron's original R33.7.1 AC (round-3 capture): "zooming OUT ... INCREASES the SIZE of the SVG diagram (the diagram CANVAS GROWS)" so there's more room for elements. Current impl scales the CONTENT (transform) but the SVG element's own dimensions stay fixed → canvas doesn't grow → no room gained.

## Why the gate passed but Tron's device shows the bug ([[device-qa-regression-means-missing-ac]])
The R33.7.1 gate asserted **scale<1 / 1=whole / persist** (zoom WORKS) — but NEVER asserted the **SVG canvas DIMENSIONS actually increase** on zoom-out. So it green-passed a "scale" while the real AC (canvas-grows-for-room) was untested. The AC needs a testable measure of the canvas GROWING, not just the scale value.
