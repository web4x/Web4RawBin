## The 4 items (Tron verbatim intent)

### Item 1 — ZOOM OUT to solve the space problem (diagram grows)
Zooming OUT is ALWAYS possible and INCREASES the size of the SVG diagram (the diagram canvas grows to make room for more elements). **Zoom level is SAVED on the diagram** (persisted per-diagram). Zoom level **1 = 100% = see the whole diagram**; when the diagram increases size by zooming out, zoom stays anchored so 1 always frames the whole diagram. So: zoom-out grows the SVG canvas → more room; the level persists on the diagram unit. (Reuse RbPanZoom — already used for R33.6.2 edge-autoscroll.)

### Item 2 — Adding an element also adds its relationships
Moving elements recalculates relationship links (= R33.6.3, already designed — reinforced). **NEW:** ADDING an element also ADDS its relationships to other elements already on the diagram (auto-wire the new element's connectors to existing elements). Couples with item-3 (discover) + R33.6.3 (reroute).

### Item 3 — "Discover relationships" action (1-level graph expansion)
NEW action-bar action on a selected diagram element: **"Discover relationships"** → adds, **1 level** from the selected element:
- its BASE CLASS + the `extends` relationship
- NAVIGATION links + the TARGET classes
- INHERITING classes (subclasses)
- IMPLEMENTED interfaces
Just **1 level** (immediate neighbors), not transitive. Fits the R33.6.5 action-bar (class-selected → [...+ Discover relationships]). Reads the model graph; adds the discovered classes + relationships onto the diagram.

### Item 4 — Selecting an element scrolls+expands the TREE to it
Selecting a diagram element → the resulting TREE (the itemview/model tree) **navigates/scrolls it into view + EXPANDS as necessary** to reveal it. (Reuse the R33.5 expandPath uuid-walk / revealNode — the reveal mechanism that's already built + gated; here triggered by diagram-element SELECTION, tree-side.)
