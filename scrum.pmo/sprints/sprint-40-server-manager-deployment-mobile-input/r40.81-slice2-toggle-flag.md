# R40.81 Slice-2 reader-source TOGGLE — flag name + contract (architect, 2026-09-06)

The minimal artifact PAIR-2 needs. NAME + contract only (not a design; Slice-2 shape is in r40.81-overlap-reconciliation.md).

- **FLAG NAME:** `MODEL_READ_SOURCE` (env var; server reads it once at the model-unit resolution point).
- **WHAT IT TOGGLES:** which store the **model-unit READ path** resolves from — the ONE resolver that Slice-2 collapses the `isModelUnit ? MODEL_STORE : scenario/index` fork into (also mofChildren + trace-merge model reads route through it).
- **TWO STATES:**
  - `model-store` → read model units from `data/model-store/index` (**PRE-repoint** = today's behaviour).
  - `scenario-index` → read model units from `scenario/index` (**POST-repoint** = one-store target).
- **WHICH READERS HONOUR IT:** exactly ONE — the collapsed model-unit resolver (Slice-2's single owner). No other reader branches on store; the fork is gone, replaced by this one flag read. (That singularity is what the toggle-removal lint asserts post-Slice-3.)
- **DEFAULT:** `model-store` (migration-window safe default — readers stay on the physically-intact MODEL_STORE until the repoint is proven).
- **PAIR-2 USAGE:** ONE scratch build, same code — capture **PRE** with `MODEL_READ_SOURCE=model-store`, **POST** with `MODEL_READ_SOURCE=scenario-index`, diff the 213-set byte-identical. Only the reader source flips → zero code drift.
- **LIVE / ROLLBACK:** flip to `scenario-index` on live only after scratch-PAIR-2 GREEN; the flip IS the rollback lever (flip back to `model-store`, MODEL_STORE intact, no rebuild).
- **REMOVAL:** post-Slice-3 the flag is DELETED and readers hardwired to `scenario-index` (the tracked toggle-removal item; lint asserts 0 reader-source branches). The flag is migration-window-only, never a resting config.
