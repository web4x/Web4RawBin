## The discriminator (semantic, shape-independent — passes "written-from-design-text-alone")
The design's hazard is **reduce-to-ONE current task**. The real discriminator between the specimen and the false positive
is **task-vs-TASK winner-selection vs task-vs-ITSELF per-item evaluation** — NOT return type (scalar vs array). Return-type
keying was a shallow proxy and is DISCARDED because it is EVADABLE (a 2nd source hides by returning `[best]` or
`{uuid:best}`) — the actor-blocklist failure in new clothing, the exact thing that let this defect ship.

- **HAZARD (must RED)** = a SINGLE-WINNER accumulator (`best`/`current`) conditionally overwritten inside the Task loop
  (keep-if-better: a task compared against the running best by recency/status), yielding ONE task uuid — returned BARE or
  WRAPPED (`return best` / `return [best]` / `return {uuid: best}` / `.at(0)` / `.sort(...)[0]`). `derivedCurrentTaskUuid`
  is exactly this (each task's `lastAdvancedAt` compared to `bestAt`, one `best` kept).
- **NOT hazard** = `.push(...)` accumulates EVERY qualifying match and returns the collection (`assertStatusConsistent`:
  each task compared to its OWN checklist `declared !== derived`, all offenders pushed → collect-all drift-detection, a
  DIFFERENT and legit hazard, out of scope for current-task single-source).
- **Signal** = single-winner reduction (a conditionally-overwritten accumulator, NO push-all), unevadable by wrapping.
